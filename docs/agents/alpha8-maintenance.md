The alpha.6 runner owns runtime recurrence and reuses its save and placement fixtures. |
| Documentation | Current state and test selection are indexed separately from historical acceptance. Existing fixture owners and version-matched evidence remain accessible. |

The new trace is event-bounded and uses the existing optional diagnostic ring. The runtime recurrence fixture stores only its latest calendar event and reports on milestone transitions. No performance improvement is claimed. Shared compilation and asset copies are deliberate isolation costs. Measure them before adding caching. Legacy pathfinding, pack ABI assumptions and cross-dimension authority need targeted evidence before changing their compatibility boundaries.

For 0.2, the first potential integration is an assessment at natural encounter admission. Define locality, decay, bounds, eviction and save ownership before adding a consumer.
