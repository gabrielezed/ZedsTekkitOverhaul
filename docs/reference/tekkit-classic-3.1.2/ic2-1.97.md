# IndustrialCraft 2 API — version 1.97 / Minecraft 1.2.5

**Status:** interface and facade names below were inspected in the user's locally supplied `industrialcraft-2-client_1.97.zip` decompilation and `api.zip`. The `api.zip` contains **29 Java source files** plus its directory entry. These files are **not** stored in Git.

The locally supplied Java text references obfuscated Minecraft symbols such as `kw`, `xd` and `aan`; **those are not valid MCP 6.2 type names**. The real installed, correctly mapped API must be checked before adding direct imports to ZTO.

## EU network: primary integration surface

| IC2 1.97 declaration | Verified members or purpose | How ZTO may use it |
| --- | --- | --- |
| `ic2.api.IEnergyTile` | `boolean isAddedToEnergyNet()` | Energy network registration state |
| `ic2.api.IEnergyAcceptor` | `boolean acceptsEnergyFrom(..., Direction)` | Determines permitted input neighbors |
| `ic2.api.IEnergyEmitter` | `boolean emitsEnergyTo(..., Direction)` | Determines permitted output neighbors |
| `ic2.api.IEnergySink` | `boolean demandsEnergy()`; `int injectEnergy(Direction, int)` | EU-consuming Foundry |
| `ic2.api.IEnergySource` | `int getMaxEnergyOutput()` | Future generators |
| `ic2.api.IEnergyConductor` | Conductor interface present; inspect all members before implementing | Future cable/interconnection work |
| `ic2.api.Direction` | Legacy direction type used by the energy API | Input/output sidedness |
| `ic2.api.EnergyNet` | `getForWorld(...)`, `addTileEntity(...)`, `removeTileEntity(...)`, `emitEnergyFrom(IEnergySource, int)` | EU network lifecycle and generation |

**Important:** the argument types represented by `...` must be translated by an MCP-compatible mapping. `injectEnergy` return-value semantics (accepted vs. remainder) and network registration timing should be verified from version 1.97 behavior before implementing a sink or generator. Do not copy modern energy examples.

### Safe design proposal for the Foundry

1. Keep a generic machine state model independent of IC2.
2. Implement `IEnergySink` in a dedicated IC2 adapter or the explicitly IC2-enabled TileEntity only after signatures have been mapped.
3. Register/deregister the real TileEntity with EnergyNet at the correct legacy lifecycle points; avoid double registration across chunk reloads.
4. Preserve buffered EU in NBT, with a documented capacity, packet/tier limit, and overflow behavior.
5. Validate real in-game power transfer with IC2 cables, an IC2 Generator and chunk reloads.

None of these energy components is currently implemented for the Foundry.

## Recipes and items

The local `ic2.api.Ic2Recipes` declares recipe accessors for **Macerator**, **Compressor** and **Extractor** and helpers for IC2 crafting recipes. Relevant examples, with production `aan` representing an obfuscated ItemStack-like parameter type, are:

- `getMaceratorRecipes()` and `addMaceratorRecipe(..., ...)`
- `getCompressorRecipes()` and `addCompressorRecipe(..., ...)`
- `getExtractorRecipes()` and `addExtractorRecipe(..., ...)`
- `addCraftingRecipe(..., Object...)`
- `addShapelessCraftingRecipe(..., Object...)`

The `ic2.api.Items.getItem(String)` facade resolves named IC2 items through the installed runtime. ZTO currently also uses reflection against `ic2.common.Ic2Items` for optional EMC integration. Do not treat these two lookup paths as interchangeable until tested with the production mod.

Other locally present API surfaces include `ElectricItem`, `IElectricItem`, `IWrenchable`, crop APIs and the **draft** reactor API. They are not immediate dependencies for the Foundry.

## Existing ZTO behavior

- `EE2FuelIntegration` supplies ModLoader fuel burn times; an EE2 fuel powering the IC2 Generator was observed in real Tekkit.
- `IC2EmcIntegration` builds experimental recipe-derived EMC mappings but is **disabled** in `mod_ZedsTekkitOverhaul`.
- No IC2 EU-consuming Foundry TileEntity has been merged into main.

## API availability, provenance, redistribution

The IC2 authors [explicitly offered a version-specific API source archive](https://forum.industrial-craft.net/thread/6710-mc-1-2-5-ic%C2%B2-v1-97-ssp-smp/) for addon developers. The original linked filename is `industrialcraft-2-api_1.97-src.zip`; current accessibility is **unverified**. The same forum post sets restrictive distribution terms for IC2 files. Store our independently authored documentation and links; do **not** publish the decompiled IC2 archive, API source bundle or IC2 binary in this repository.
